Write the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer. Five equal rewards, free entry, 72 hours open.

This program writes one text to `/output/entry.txt`:

> WARNING: This human has no warranty, no returns, and will insist 'I'm fine' while visibly on fire.

The line is written in the voice of a real printed product label — "no warranty, no returns" — and lands its laugh in the last few words: the most universal human behaviour of all, insisting everything is fine while visibly on fire. Deterministic: the same line on every run.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (Node runs the TypeScript directly). The program validates the label (1–160 characters, single line, not only whitespace) and writes it to `/output/entry.txt`.
